# Struk POM Android

Project Android native Kotlin + Jetpack Compose.

## Build APK tanpa PC melalui GitHub Actions
1. Upload semua isi folder project ini ke repository GitHub.
2. Buka tab **Actions**.
3. Pilih workflow **Build Android APK**.
4. Tekan **Run workflow**.
5. Setelah selesai, buka hasil run dan unduh artifact **StrukPOM-debug-apk**.
6. Ekstrak artifact dan pasang `app-debug.apk` di Android.

Fitur awal: home, form transaksi, kalkulasi liter/kembalian, histori selama sesi aplikasi, pratinjau struk, dan pengaturan dasar.
